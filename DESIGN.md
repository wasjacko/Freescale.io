# DESIGN.md — Ultra Modern Minimal SaaS UI System

## Vision

Créer une interface premium, minimaliste, émotionnelle et ultra moderne inspirée des meilleurs standards UI actuels.

Références principales :

* Linear
* Notion Calendar
* Raycast
* Arc Browser
* Stripe Dashboard
* Vercel
* Apple UI
* Framer
* Superhuman
* Attio

L'objectif est de générer des interfaces :

* très aérées
* élégantes
* extrêmement lisibles
* émotionnelles mais sobres
* modernes sans être "gadget"
* premium et cohérentes
* minimalistes mais riches en détails

Le design doit donner une sensation :

* de fluidité
* de calme
* de précision
* d'intelligence
* d'efficacité
* de produit haut de gamme

---

# CORE DESIGN PRINCIPLES

## 1. MINIMALISME INTELLIGENT

Toujours supprimer le bruit visuel.

Éviter : bordures inutiles, couleurs agressives, ombres fortes, gradients excessifs, éléments décoratifs inutiles, contrastes trop violents.

Favoriser : l'espace vide, hiérarchies claires, layouts respirants, surfaces soft, transitions fluides, détails subtils.

## 2. SPACING PREMIUM

cards : padding 24–32px · sections : 40–72px · gap principal : 20–32px · radius large : 20–28px.

# VISUAL LANGUAGE

## Radius System
Utiliser uniquement : 12 / 16 / 20 / 24 px.

## Shadow System
Max 2 styles d'ombres : soft + floating. Exemple : `0 10px 40px rgba(88,92,255,0.08)`.

## Button Sizes
Small 36 · Medium 44 · Large 52.

## Color System
Backgrounds : #FAFAFC / #F6F7FB / #F8F8FD. Headings : #0F172A / #111827. Body : #5B6475 / #667085. Pas de noir pur, pas de blanc pur.

## Typography
**Geist** (principal) — SF Pro Display (secondaire). Max 5 tailles, 3 weights.

# AI DESIGN LANGUAGE

Douce, lumineuse, émotionnelle. Dégradés doux + blur + glow subtil. Jamais néon, jamais sci-fi excessif.

# ANIMATION
hover 180ms · panel 300ms · easing `cubic-bezier(0.16, 1, 0.3, 1)`.

# TEXTURE & NOISE
2–8% noise sur gradients premium. Subtil, haute fréquence, jamais agressif.

# ALWAYS
Espace vide · hiérarchie claire · cohérence parfaite · couleurs douces · sensation premium · calme visuel · animations fluides.

# DO NOT
Couleurs flashy · trop d'ombres · bordures épaisses · UI compressé · trop de texte · icônes agressives.
